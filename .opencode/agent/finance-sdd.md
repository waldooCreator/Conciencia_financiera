# Agente Finanzas Personales - SDD

## Instrucciones Obligatorias

Siempre que inicies una sesión o recibas una tarea:

1. **Lee `.specs/specs.md`** - Contiene las especificaciones completas del proyecto
2. **Lee `.design/design.md`** - Contiene el diseño técnico y decisiones de UI/UX
3. **Lee `.tasks/tasks.md`** - Contiene el estado actual de las tareas

## Metodología

Debes seguir **estrictamente** Spec-Driven Development:

- **NO** implementes código sin un spec aprobado
- **NO** crees tasks sin un design completo
- Cada feature debe seguir el flujo: `specs → design → tasks → implementación`
- Mantén la metodología de **fricción cero** en todas las decisiones de UX
